## NAME
podman\-config - Manage configs

## SYNOPSIS
**podman config** *subcommand*

## DESCRIPTION
podman config is a set of subcommands that manage configs.

## SUBCOMMANDS

| Command | Man Page                                               | Description                                            |
| ------- | ------------------------------------------------------ | ------------------------------------------------------ |
| create  | [podman-config-create(1)](podman-config-create.1.md)   | Create a new config                                    |
| exists  | [podman-config-exists(1)](podman-config-exists.1.md)   | Check if the given config exists                       |
| inspect | [podman-config-inspect(1)](podman-config-inspect.1.md) | Display detailed information on one or more configs    |
| ls      | [podman-config-ls(1)](podman-config-ls.1.md)           | List all available configs (alias list)                |
| rm      | [podman-config-rm(1)](podman-config-rm.1.md)           | Remove one or more configs                             |
